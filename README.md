# Sistema de Gestión de Envíos

<h6>Este programa tiene como finalidad el manejo de dinero con la simulación de un cajero automático.</h6>

<h5>Procesos por realizar en el programa: </h5>
<ul>
  <li>Consulta de Saldo</li>
  <li>Retiro de dinero</li>
  <li>Ingreso de dinero</li>
  <li>Consulta de movimientos en un resumen</li>
</ul>
<h5>Calculos realizados</h5>
<ul>
  <li>El calculo de los ingresos de dinero</li>
  <li>El calculo de los egresos de dinero</li>
  <li>El conteo de las transaciones correctas e incorrectas realizadas</li>
</ul>

<h5>Instrucciones para ejecutar el proyecto</h5>
Se debe inicializar la compilación del proyecto presionando el botón con forma trinangular en la parte superior del mismo, para después en la consola seleccionar la opcion que se desee utilizar digitando el número requerido, teniendo en cuenta que el sistema no finalizará hasta no seleccionar la opción 6 de salida.
