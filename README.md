# Sistema de Gestión de Envíos

<h6>El proyecto presente es para el buen funcionamiento y la redución en la perdida de información para que se lleve un control como se debe. </h6>

<h5>Objetivo del programa: </h5>
<ul>
  <li>Optimización de tiempo</li>
  <li>Calcular correctamente los montos</li>
  <li>Poca perdida de información</li>
  <li>Aprendizaje de POO</li>
</ul>
<h5>Temas aplicados</h5>
<ul>
  <li>Herencia</li>
  <li>Encapsulación</li>
  <li>Polimorfismo</li>
</ul>

<h5> Estructura del Prooyecto </h5>
<ul>
  <li>Envio : Constructor, calculo de costo base y los dos metodos de resumen</li>
  <li>Envio Nacional : Hereda de Envio y agrega departamento y distancia, y sobreescribe el cálculo de costo final.</li>
  <li>Envio Internacional : Hereda de Envio y agrega país y sobreescribe el cálculo de costo final.</li>
  <li>Main : Menú, registro y validación de datos, resumen</li>
</ul>

<h5> Instrucciones para la Ejecución del Proyecto </h5>
Se debe inicializar la compilación del proyecto presionando el botón con forma trinangular en la parte superior del mismo, para después en la consola selecionar la opción deseada utilizando solamente números del 1 al 3, se ingeresan los datos que el sistema solicita paso a paso, una vez finalizado se mostrará el resumen y se consultará si desea realizar otro registro o no.
